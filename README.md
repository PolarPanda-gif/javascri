#gamelet

A starter program writing .Javascript games.

## usage

1. include gamelet.js in an HTML document containing an element with an id of 'ball'.

```html
<div id="ball"></div>
<scipt src="gamelet.js" />
```

2. THe script will detect the left or right arrow keys when pressed and will move the ball element accordinly // goal

3. constants cannot be changed

4. date function finds out date on persons computer

5. default case is if none of the cases match
